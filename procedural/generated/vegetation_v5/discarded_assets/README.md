# Discarded V5 tree assets

This directory preserves the rejected V5 versions of `tree_3d_01`,
`tree_3d_04`, `tree_3d_05` and `tree_3d_06` before their replacement.

- `trees/` contains 40 GLBs: four silhouettes, five material variants and two
  LODs.
- `review/` contains the 12 individual audit renders that existed for those
  silhouettes.
- `manifest_before_tree_replacement.json` is the complete catalog manifest
  from immediately before the archive operation.

These files are retained only for comparison and recovery. They are not part
of the current production manifest.

The later removal of `tree_3d_06` from the replacement catalog is preserved
separately under `removed_tree_3d_06/`, including 10 GLBs, two audit renders
and the manifest captured immediately before removal.
